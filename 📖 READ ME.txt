✦ MOCHI · QUICK START ✦
=======================

🚀 FIRST TIME: Open the Install-Mochi launcher for your OS (Windows / Mac / Linux).
🐧 Linux opens as text? Open a terminal here: sh ./Install-Mochi-Linux.sh
▶  NEXT TIME: Double-click Run Mochi Now.
🐧 Linux shortcut blocked? Right-click → Allow Launching; fallback: sh .mochi/run.sh
🔗 Paste a YouTube link → choose → Make it happen.
📁 After a download: choose Open folder.
📝 After a transcript: Open transcript / Copy for AI / Open folder.
💾 In hidden .mochi/: keep Downloads; cache is safe to clear when closed. AI is optional.
🔄 Updating: extract a newer Mochi.zip into this same folder, keep .mochi, and run Install-Mochi again.
🔖 Browser bookmarks can expire after a restart. Use Run Mochi Now to reopen.
🛠 Stuck? Fix my tools (top right).
